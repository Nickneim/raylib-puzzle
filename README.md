# RaylibPuzzle

A small game engine skeleton for puzzle games, made with Raylib.

Still a Work In Progress.

Build with CMake. Can be compiled for web with emscripten, which supports mobile :)

Inspired by [PuzzleScript](https://www.puzzlescript.net/). Currently has Microban-1 levels and Sokoban rules, but this can be replaced by editing `gameplay/GameplayLogic.cpp` and `resources/levels.txt`.

Includes: An Undo system. Level Select. Simple animations. Mobile Gamepad. Low coupling (hopefully). Level Editor (kind of). Mouse support.
